# Mobil Uygulama Dokümantasyonu

| Belge | Amaç | Durum |
| --- | --- | --- |
| [`architecture.md`](architecture.md) | Uygulama mimarisi, modüller, durum yönetimi ve kullanılan teknolojiler | Ana teknik başvuru |
| [`report-addendum.md`](report-addendum.md) | Final raporuna aktarılacak tarihsel değişiklik özeti | Rapor eki |

Kodla belge çeliştiğinde `lib/` altındaki güncel uygulama yapısı esas alınır. Yeni bir genel mobil belge oluşturmak yerine uygun başlığı `architecture.md` dosyasına ekleyin. Tek bir özelliğin kullanım notu gerekiyorsa belgeyi ilgili modülün yanında tutun.
